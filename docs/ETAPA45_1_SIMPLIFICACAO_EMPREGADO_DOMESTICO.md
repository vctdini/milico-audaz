# Etapa 45.1 — Simplificação do empregado doméstico

- Removido o formulário de identificação e as declarações de vínculo/registro.
- A opção “Empregado doméstico” é uma seleção simples, sem perguntas adicionais.
- Se marcada, as tarifas de passagem lançadas na categoria “Empregado doméstico” entram na soma.
- Se desmarcada, essas tarifas são ignoradas no cálculo, mesmo que tenham sido preenchidas.
- A memória de cálculo lista somente os itens selecionados.

A calculadora executa a simulação conforme os dados informados pelo usuário, sem fazer triagem documental ou decidir elegibilidade.
